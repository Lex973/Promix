# Служебные скрипты

Не часть темы, на сайт не копируются. Нужны при развёртывании магазина
на новом сервере (Local сейчас, TimeWeb потом).

- `wc-setup.php` — настройка WooCommerce после активации: рубли, Россия,
  выключенные отзывы/купоны/налоги, страница каталога как «магазин», адреса
  `/catalog/…` и `/product/…`. Положить в корень сайта, заменить `СЕКРЕТ`,
  открыть `/wc-setup.php?k=СЕКРЕТ`, удалить файл.
- `wc-import-csv.py` — собирает `woo-import.csv` из `katalog-dlya-sayta.csv`
  (прайс, в git не идёт). Результат загружается через «Товары → Импорт»
  в админке; колонка Brands — штатные бренды WooCommerce («Товары →
  Бренды»), импортёр создаёт их сам.
- `wc-descriptions.py` — собирает `woo-descriptions.csv` (артикул, краткое
  и полное описание) из того же прайса. Тип товара определяется по
  ключевым словам в названии (словарь `TYPES` в скрипте — туда же
  дописывать новые типы), бренд и раздел берутся как есть; выдуманных
  характеристик нет, о расходе и составе текст отсылает к паспорту
  производителя. Грузится через «Товары → Импорт» с галочкой «Обновлять
  существующие товары» — совпадение по артикулу. Краткое описание идёт
  в мета-описание страницы товара.

## Подключение MAX

1. В приложении MAX открыть **@MasterBot**, создать бота (`/newbot`), скопировать токен.
2. В `wp-config.php` добавить `define( 'PROMIX_MAX_TOKEN', '<токен>' );`.
3. Менеджер пишет боту любое слово (или добавляет бота в групповой чат
   и пишет там). В админке «Инструменты → MAX» появится номер чата.
4. В `wp-config.php` добавить `define( 'PROMIX_MAX_CHAT', <номер> );`.
5. Там же нажать «Отправить тестовое сообщение» — оно должно прийти в чат.

Дальше каждая заявка и каждый заказ уходят в этот чат сами. Если не
ушло — у заявки в списке пометка «в MAX не ушло», у заказа заметка
с текстом ошибки; письмо при этом всё равно отправляется.
